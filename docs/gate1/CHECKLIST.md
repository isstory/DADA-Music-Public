## 발견 사항
1. **시트 DB 쓰기 지연:** 플레이리스트 쓰기 1회 약 0.6~3초, 순서 변경+빼기 약 5.6초 (잠금 + 시트 전체 재기록). 2인 사용에는 허용 범위지만 체감이 느릴 수 있음 → 화면은 낙관적 업데이트(좋아요는 적용됨) 확대, 필요 시 CacheService 캐시 도입.
2. **검색 품질:** 방송 무대 영상 감점 규칙 추가. 남은 한계(멤버 버전 MV 등)는 Gate 2에서 매칭 고도화.
3. **휴대폰 사용:** Google 로그인은 HTTPS 주소 필요 → 무료 호스팅 배포 필요 (미진행).
