## 2. 인증·인가 (백엔드)
- Google 로그인(OpenID Connect, 리디렉션 방식, state·nonce 검증) → 서버가 ID 토큰을 `tokeninfo`로 검증(aud=우리 클라이언트, 이메일 인증, 허용 목록) → **30일 세션** 발급.
- 세션 원문은 클라이언트에만, 서버에는 **SHA-256 해시만** 저장. 사용 중 자동 연장, 로그아웃 시 삭제, 허용 목록에서 빠지면 즉시 무효.
- 모든 데이터 API는 세션 필수. 플레이리스트·라디오·동기화는 소유자(`ownerKey`) 확인, 타인 목록은 존재 여부도 숨김(not_found).
