# Gate 2 — AI 라디오 검증표

흐름: 좋아하는 노래(씨앗, 최대 20곡) + 지역(국내/해외/국내+해외) + 곡 수(20/30)
→ Gemini(gemini-2.5-flash, JSON 스키마 응답) 추천 (목표 + 8곡)
→ 곡마다 YouTube 검색으로 실제 곡 확인 (제목 일치 시에만 채택, 지어낸 곡 제거)
→ 사용자별 라디오 플레이리스트 1개 갱신 + 곡별 추천 이유 저장
→ YouTube Music으로 보내기 (Gate 3 동기화) → "YouTube Music에서 듣기"

## 자동 검증
| ID | 항목 | 판정 | 비고 |
|---|---|---|---|
| G2-0 | 추천↔검색 결과 매칭 규칙 단위 시험 (6건) | PASS | 한글 추천 ↔ 영문+괄호 한글 제목, 지어낸 곡 거부 |
| G2-1 | Gemini 추천 → YouTube 확인 → 라디오 생성 (실제 API) | PASS | 20곡 채택, 못 찾음 0, 46초, 2,020 units |
| G2-2 | 씨앗 곡은 라디오에서 제외 | PASS | |
| G2-3 | 모든 곡에 추천 이유 | PASS | 예: "섬세한 감성 보컬의 따뜻한 위로." |
| G2-4 | 국내+해외 혼합 | PASS | 한글 표기 10/20 |
| G2-5 | 라디오 소개 문구 | PASS | |
| G2-6 | 화면: PC·모바일 390px | PASS | 데모 모드 스크린샷. 한글 단어 중간 줄바꿈 수정 |
| G2-7 | 제목 정리: 앞뒤 따옴표 잔여 | 수정 | 자가 진단에서 발견 → 수정·재배포 (기존 캐시 곡은 그대로) |

## 비용
- 라디오 1회(20곡, 캐시 없음): 검색 약 2,000 + 보내기 약 1,150 ≈ **3,200 units** → 하루 약 3회
- 같은 곡을 다시 추천받으면 검색 캐시(7일)로 차감 없음 → 쓸수록 감소
