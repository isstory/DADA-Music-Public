# Gate 3 — YouTube Music 동기화 검증표

판정: **PASS** / **FAIL** / **UNVERIFIED**

## 동기화 전략
| 경우 | 동작 | 비용 (30곡 기준) |
|---|---|---|
| 지난번과 곡·순서 동일 | 생략 (skip) | 약 1 unit |
| 뒤에 곡만 추가 | 기존 YouTube 목록에 추가분만 삽입 (append) | 50 × 추가곡 |
| 그 외 (순서 변경·삭제 등) | 새 목록 생성 → 순차 삽입 → 실제 조회로 검증 → 통과 시 교체·구 목록 삭제 (swap) | 약 1,600 |

- 검증 실패 시 기존 목록을 그대로 둔다(사용자는 이전 목록으로 계속 들을 수 있음).
- 계정 A 본인 목록은 비공개, 다른 사용자(B) 목록은 일부 공개(링크로 재생).
- 동시 실행·이중 클릭 방지, 시작 전 남은 할당량 확인, DADA 목록 삭제 시 YouTube 사본도 삭제.

### 자가 진단으로 발견·수정한 결함
1. **연속 삽입 409 오류:** 같은 목록에 곡을 빠르게 연속 삽입하면 YouTube가 간헐적으로 `The operation was aborted`를 반환 → 1·2·4초 백오프 재시도 추가. 이후 제외 곡 0.
2. **제외 곡 때문에 영원히 '변경됨':** 기록을 "실제 들어간 곡" 기준으로 저장해 skip/append가 작동하지 않고 매번 전체 교체(할당량 낭비) → "요청한 곡"과 "제외된 곡"을 분리 저장.
3. **append 검증 실패 시 중복 삽입 위험:** 실패 시 기록을 비워 다음 보내기는 반드시 새 목록 교체로.
